## 键盘路径

Electron E2E 仅用聚焦与 `Enter` 完成以下路径：

1. 打开应用内项目菜单，使用 Home/End 在两个项目间切换，并使用 Escape 关闭并回到触发按钮。
2. 从顶部状态摘要和分段控件切换提案筛选。
3. 打开提案详情。
4. 定位当前任务，焦点落到目标任务行。
5. 在任务执行与上下文文档间切换。
6. 从提案详情直接返回执行台。

## 辅助技术名称

- 图标导航同时提供 `aria-label`、`aria-current` 和鼠标悬浮说明。
- 项目选择按钮使用 `aria-haspopup` 和 `aria-expanded`，listbox 项目项使用 `aria-selected` 表达当前项目。
- 刷新、管理、关闭、复制、重新关联、移除按钮均暴露完整命令名称。
- 状态使用文本与图标，进度使用 `role="progressbar"`、精确数值和 `aria-valuetext`。
- 项目管理对话框使用原生 `dialog`，标题关联 `aria-labelledby`，状态区使用 `aria-live`。
- 自动规则以 WCAG 2 A/AA、2.1 AA 和 2.2 AA 为下限；严重与关键违规为零。

## 人工截图复核

- 820x640 首屏可到达项目入口、导航、刷新、筛选和首个提案，三个 fixture 提案均在视口内。
- 1180x760 详情将上下文下移，任务主轴保持完整宽度。
- 1440x930 详情并列展示任务与次级上下文，当前任务和精确进度优先。
- 项目选择菜单使用侧栏一致表面，当前项、可切换项和路径失效项具有独立的文字、图标与选中反馈。
- 执行台默认恢复进行中、待归档、需要处理状态总览；摘要与聚焦列表筛选统一为活跃、进行中、待归档、需要处理顺序，选中态和列表标题同步。
- 深色文档保持相同标题、标签、目录、正文、表格和代码层级。
- 项目管理清楚区分当前项目、健康项目与路径失效项目，并在移除前说明不会删除文件。

## 分发包复核

- macOS arm64 应用与 ZIP 构建成功，打包应用通过完整 E2E 和全部视觉基线。
- macOS x64 应用与 ZIP 构建成功，并在 Apple Silicon 的 Rosetta 环境通过完整 E2E。
- 两份 ZIP 均通过 `unzip -t` 完整性检查，可执行文件分别确认为 arm64 与 x86_64。
- 打包版 E2E 覆盖窗口拖动区域、项目切换、项目重新关联与移除、真实项目只读读取、单实例和无本地监听端口边界。
