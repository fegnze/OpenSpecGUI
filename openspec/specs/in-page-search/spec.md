# In-Page Search Specification

## Purpose

让用户能在当前工作台页面的可读内容中快速定位文本，而无需离开当前阅读上下文或改用跨文档搜索，并清晰区分页内定位与跨文档的全局搜索。

## Requirements

### Requirement: 用户可以通过标准快捷键启动页内查找
系统 SHALL 在工作台内容视图获得焦点时，将 macOS 的 `⌘F` 和其他平台的 `Ctrl+F` 映射为页内查找操作。启动操作 MUST 显示页内查找控件、聚焦其查询输入框，并且不得打开或修改全局文档搜索。

#### Scenario: 使用 macOS 页内查找快捷键
- **WHEN** 用户在工作台页面中按下 `⌘F`
- **THEN** 系统显示页内查找控件并将焦点置于查询输入框
- **AND** 顶部全局文档搜索查询保持不变

#### Scenario: 使用非 macOS 页内查找快捷键
- **WHEN** 用户在工作台页面中按下 `Ctrl+F`
- **THEN** 系统显示页内查找控件并将焦点置于查询输入框
- **AND** 浏览器或宿主的默认查找行为不会与该控件重复出现

### Requirement: 用户可以查看并导航当前页面的匹配项
系统 SHALL 在当前工作台主内容区内对非空查询进行不区分大小写的文本匹配，高亮所有匹配项，并显示当前匹配位置与总数。用户 MUST 能通过前一处、后一处以及 Enter 和 Shift+Enter 在匹配项间循环导航，且当前项必须滚动到可见位置。

#### Scenario: 查询产生多个匹配项
- **WHEN** 用户输入在当前工作台主内容中出现多次的文本
- **THEN** 系统高亮全部匹配项并显示总数
- **AND** 系统清晰区分当前匹配项
- **AND** 用户可以前后循环定位每一项

#### Scenario: 查询没有匹配项
- **WHEN** 用户输入未出现在当前工作台主内容中的文本
- **THEN** 系统显示零个匹配项
- **AND** 前一处和后一处操作不会改变页面路由或抛出错误

### Requirement: 页内查找状态必须受当前页面生命周期约束
系统 MUST 将页内查找限定在当前渲染的主内容中，不得匹配工具栏、侧边栏或查找控件本身。查询被清空、查找被关闭或页面内容重新渲染时，系统 MUST 清除已添加的高亮和匹配状态；关闭后，用户可以继续正常浏览页面。

#### Scenario: 切换到另一页面
- **WHEN** 用户在页内查找处于打开状态时切换工作台路由或触发页面重新渲染
- **THEN** 系统移除旧页面的匹配高亮和结果计数
- **AND** 新页面不会显示过期的查找结果

#### Scenario: 关闭页内查找
- **WHEN** 用户按 Escape 或选择关闭操作
- **THEN** 系统隐藏页内查找控件并清除查询和高亮
- **AND** 页面内容保持可读且当前路由不变
