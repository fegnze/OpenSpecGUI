## ADDED Requirements

### Requirement: 规划文档支持页内文本定位
系统 SHALL 在工作台呈现的主内容页面中提供与桌面平台一致的页内文本定位能力。该能力 MUST 与跨提案、规范和任务的全局搜索保持独立，并且不得改变全局搜索的 `/` 快捷键或其结果范围。

#### Scenario: 区分页内查找与全局搜索
- **WHEN** 用户在已打开的提案、规范或其他工作台页面中启动页内查找
- **THEN** 系统只在当前主内容中显示匹配和导航结果
- **AND** 不离开当前路由、不生成全局搜索结果页

#### Scenario: 使用全局搜索快捷键
- **WHEN** 用户在没有编辑文本输入控件的工作台页面中按下 `/`
- **THEN** 系统继续聚焦顶部全局搜索框
- **AND** 不打开页内查找控件
