## Purpose

让团队成员能从同一个本机工作台接入 DeepSeek Harness 桌面应用，为每个工作树单独选用团队能力，并通过该宿主的原生机制获取上下文和执行已覆盖的工具检查。

## ADDED Requirements

### Requirement: 桌面宿主可逆接入

工作台 SHALL 识别本机 DeepSeek Harness 桌面版，显示版本、目标文件及事件，经成员点击后注册原生插件，按台账解除。检测 SHALL 保持只读。

#### Scenario: 接入并解除

- **WHEN** 成员对支持的桌面版接入、重试并解除
- **THEN** 宿主加载单份工作台插件，解除时保留其他插件、用户配置及手工登记
- **AND** 有冲突的声明得到保留，界面提供冲突提示

### Requirement: 按项目及宿主解析生效的能力

工作台 SHALL 按实际工作树和目标宿主保存与解析绑定。插件 MUST 通过宿主原生上下文和工具检查接口处理受支持的本机编辑，保持宿主的权限决定。

#### Scenario: 打开本机已绑定项目

- **WHEN** DeepSeek Harness 为已绑定的工作树组装模型上下文或检查受覆盖的编辑
- **THEN** 只采用该工作树的 DeepSeek Harness 绑定，工具检查把明确的拒绝返回宿主

#### Scenario: 无本机映射或未绑定

- **WHEN** 宿主无法证明工作树对应本机路径，或项目仅有其他宿主的绑定
- **THEN** 此会话不继承其他工作树或其他宿主的能力
