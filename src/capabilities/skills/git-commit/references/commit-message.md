# 提交信息参考

仅在提交详情结构不明确或需要示例时读取。

## 标准结构

```text
[类型] 产品代号：简要描述

说明本次提交解决的问题或达成的结果。

## 变更文件
- path/to/file

## 变更内容
1. 改动点及其目的
2. 关键边界或兼容处理

## 验证结果
- 已通过的检查

## 已知边界
- 未覆盖或特意排除的范围；没有则省略
```

## 示例

```text
[fix] dh：补齐入口占位符 controller 契约

避免资源尚未下载时点击入口占位符触发缺失方法错误。

## 变更文件
- src/resource_v2/loaders/FlagStoneLoader.js

## 变更内容
1. 为占位符 controller 补充安全的默认方法
2. 在普通和大入口占位符创建后统一安装契约

## 验证结果
- ES5 ESLint 通过
- 相关入口回归通过
```

标题保持简洁，详情只记录真实改动、验证和边界，不复制无关过程日志。
