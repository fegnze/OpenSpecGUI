# 来源与运行条件

源自 `fegnze/my-space@bb39a55` 的 `skills/feishu-defect-agent`。许可见本目录的 [LICENSE](LICENSE)。此分发版调整了绑定和宿主发现说明。1.2.0 按当前 Git 工作树和宿主发现显式绑定的项目设置。

需要 Node.js 22 或更新版本、Git 和支持项目查询的官方 Meegle CLI。为每个检出准备单独的绑定。在工作台分别启用 Codex 或 Claude Code 的绑定。1.2.0 可按当前工作树与宿主选择设置。固定旧版可在工作台升级，或显式指定当前绑定文件。需要覆盖时使用 `--binding FILE`。个人 Meegle profile 持有项目访问身份。飞书应用的消息凭据和权限、QA 群成员资格、当前人员与 IM 身份映射决定消息通道能否使用。工作台里飞书 Tool 的只读授权只能用于其声明的操作。

排查模式会按用户选定的目标写回缺陷结论。直接修复模式另外依赖绑定工程提供的验证、提交、推送、发布和复核入口及权限，按该工程约定处理交接文档。每个执行环境使用自己的授权与交付工具。
